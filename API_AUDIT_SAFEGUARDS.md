## Reload authorization and rollout

`POST /api/dashboard/reload` now requires the server environment variable
`MIMIR_RELOAD_SECRET` and a matching `X-Mimir-Reload-Key` request header.
The comparison is constant-time. Missing server configuration returns HTTP 503;
missing or incorrect caller credentials return HTTP 403. Both checks happen
before scheduling any data work, including when a reload is already running.

The secret belongs only in the API's server environment and authorized service
or administrator tooling. Do not put it in a browser, a `NEXT_PUBLIC_` variable,
a URL, source control, or reuse the export proxy secret. No secret is supplied
or generated by this change.

If the HTTP maintenance endpoint is required, configure the same new secret on
the API and its authorized caller, and update that caller to send the header
before deploying this change. If no HTTP caller is required, the secret can
remain absent and the endpoint stays disabled. An authorized `Reloading...`
response means the background task was scheduled; it is not a completion
receipt. Verify `/ready` and the active release after maintenance.

## Public company and brief behavior

- A company with positive prime obligations but no valid mapped platform now
  retains its government customers, capabilities and NSNs. Each module has its
  own exception boundary, so a failed platform query no longer skips them.
- The existing immediate lead-preview request and response contract remains.
  Its company identity and prime amount now come from the server profile rather
  than browser-supplied labels or financial totals. The prime observation period
  is read from loaded records instead of saying `FY18–Present`.
- The prompt reports net prime obligations separately from tracked subcontract
  award value. It uses the full network total when present, and explicitly labels
  a displayed-partner-only subtotal when that is all the payload supports. It
  no longer instructs the model to call their sum revenue, infer supplier tier,
  sole-source status, switching costs, recurring revenue or a protective moat.
- The agency headline states an observed amount; missing agency information no
  longer produces a claim of diversification. Platform associations are labelled
  as Mimir mappings. These safeguards reduce unsupported narratives but do not
  constitute claim-level source verification or government-source citations.
- The NSN requested five-year window advances at the federal October fiscal-year
  boundary. A requested window is not a guarantee that all records are available;
  pipeline completeness remains a separate release requirement.
- Legacy brief database work runs off the asynchronous HTTP event loop through
  Starlette's existing AnyIO thread pool. It shares the `ANYIO_THREADS` service
  limit (default 12), instead of opening a separate asyncio executor. Queries
  still run sequentially within a brief; pooled reads and the existing locked
  connection paths retain their synchronization. This does not establish a
  per-user rate limit or a bounded inference-cost budget.
- The public NSN runtime fallback preserves an unknown reorder assessment as
  `null` and forwards source/snapshot dates, release/product identifiers and
  the stock used for the reorder comparison when supplied upstream. These are
  additive runtime fields; this release does not modify the public projection,
  DLA materializer, warehouse, or existing data releases.

## Outstanding commercial and security decisions

The legacy `/api/public/unlock-brief` endpoint remains unauthenticated and
unmetered. The separate frontend `/api/company/ai-summary` endpoint is not
changed here. **Inference abuse/cost control is not resolved by this batch.**

A subsequent coordinated change should put legacy inference behind an
authenticated server proxy or a server-issued verified-lead preview token,
with quotas, concurrency bounds and request idempotency. The frontend must
migrate with that backend gate so the immediate preview is not unexpectedly
broken. The browser's `mimir_lead_captured` localStorage flag does not authorize
server-side paid inference. Header-presence bypasses in the older company/NSN
lookup quotas also remain outstanding.

## Local validation

`test_api_audit_safeguards.py` adds 14 focused tests covering reload denial and
authorized scheduling, empty/invalid platform data and independent modules,
server-derived brief evidence, unknown-company inference suppression, federal
fiscal-year rollover, and the NSN fallback's `null`/`false`/`true` assessment plus
provenance fields. The integration checks the real child, parent, and
reference-only profile response contracts and confirms concurrent briefs share
the service thread limit without blocking the event loop. All pass. The combined
run with the existing reload/public-award, platform consumer, public
projection/release, ETL automation and source automation tests passed 75 tests.

The tests mock inference, data access and reload scheduling; they do not contact
production, send email, bill an account, or mutate a live release. Run with the
project dependencies and dummy AWS/OpenAI environment values, metadata lookup
disabled, and a temporary `LOCAL_CACHE_DIR`. Missing local runtime dependencies
or OpenAI initialization settings are test setup errors, not production test
results. Root review may run a broader combined suite.
